both
the Allegro Delivery program and the Allegro DPD Courier option outside Allegro Delivery and specified the parcel weight for this option.
What changes we announced
We will disable the Allegro DPD Courier delivery option outside Allegro Delivery.
We will enable the
weight variant of the Allegro DPD Courier delivery option within Allegro Delivery
, and we will disable the other options from the Allegro Delivery program.

What prices we will set in your Allegro Delivery shipping price lists
If your shipping price list only includes the Allegro DPD delivery options outside Allegro Delivery
We will set maximum delivery prices for all options within the Allegro Delivery program, even if you enable Allegro DPD delivery options for 0 PLN.
Exception
: We will always set the highest delivery prices for the Allegro DPD Courier option (weight variant).
If you have Allegro DPD delivery options both within and outside Allegro Delivery in your shipping price list
If you have set a maximum price for the Allegro Delivery options — we will set maximum delivery prices for all Allegro DPD delivery options within the Allegro Delivery program
If you have set 0 PLN for the Allegro Delivery program options — we will set free delivery for all Allegro DPD delivery options within the Allegro Delivery program.

At any time, you can set the price to maximum for all delivery options, or set free delivery for the entire Allegro Delivery shipping price list.
