What you can save as a template
You can save default values for the following fields as an offer template:
Product condition
VAT invoice
VAT rate
Offer duration
Delivery — a selected shipping price list
Sales policy — terms of returns, complaints, and warranty
Additional services.
You do not have to provide values for all these fields. You can save only the ones that you need.
Where you can use an offer template
In all marketplaces
— both on allegro.pl and in foreign ones.
Right now, only when you list an offer
through the form
— but we are working on making templates available also when listing from a file or through the API.
How you can manage your offer templates
In the
Offer templates
tab, you can freely manage your templates by creating new ones, editing, or deleting the existing ones. You can select the default template that we will suggest when you list an offer. See how to create a new template.
Go to the
Offer templates
tab.
Click [create a new template].
Provide a name for that template. This name will help you find it in the template list and the listing form.
Complete the selected fields with values that you want to save as a template. You can leave some of them empty.
Click [save template].
Done! Your template will appear in the list in the
Offer templates
tab. Now, you can also select it when listing an offer.

When you list a new offer through the form, you can see the [create a template] button on the confirmation page. Click it to create a new template with the details of the offer you just listed so that you can use it for other offers.

How to list an offer from a template
Go to the
listing form
.
Find and select the product you want to link to your offer.
At the bottom of the page, you will see the
Choose offer template
section. There, select the
List with template
option.

We only display the
Choose offer template
section if you have at least one saved template.

Select the template you want to use for that offer from the drop-down list.
Click [fill out the form].
We will redirect you to the listing form — but this time, the fields included in the selected template will be completed. You can continue listing an offer like before.
