Check what you can set and where to do it. You can edit your settings at any time.
How to access the Ship with Allegro settings
You can find the
Ship with Allegro
in the
Delivery settings
tab.
Go to the
tab
tab and click [go to settings] in the
Ship with Allegro Settings
section.
You will see three groups of options concerning Ship with Allegro on the left.
What you can adjust
When you click a given group of options in the
Delivery settings
, you can:
save the details we will automatically complete the dispatch form with
select the default label format
add the InPost Integration to Ship with Allegro
.
InPost integration within Ship with Allegro
You can enter the details of your own agreements with InPost into the Ship with Allegro tool.
How to dispatch InPost parcels through Ship with Allegro
You need an ShipX API token to dispatch InPost Parcels via Ship with Allegro. You can add it in the
InPost Integration
tab.
How to add the InPost integration to Ship with Allegro
Sign in on the
InPost Parcel Manager
page.
Go to the Moje Konto (My Account) tab, and then to the API tab.
Generate a new (or copy an existing) ShipX API token.
Go to the
InPost Integration
tab in the Ship with Allegro settings.
Click [Add a ShipX API token] if you do not have the integration yet, or [Update] if you have already added the integration.
Paste the token.
Save the changes. Done!
See the
guide on how to get the token step by step
(available in Polish).
Done! Now you can take advantage of this agreement
when dispatching parcels through the Ship with Allegro tool
.
Your personal details in the Address Book
You can save all the addresses you use as a sender in the Address Book. You can use them when dispatching parcels through Ship with Allegro.
You can also remove and edit the saved addresses. To do that, click the icons on the right.

If you dispatch parcels with payment on delivery, you will see an additional section —
Payment on delivery
in the dispatch form. In the case of orders on allegro.pl you settle within Allegro Standard, we fill out this section with details of the account you provided in
Payout Settings
.
Check the details
.

How to add an address to the Address Book
In the
Delivery settings
, go to the Ship with Allegro Settings, and then select the
Address Book
tab.
Click [add new address] and complete the details.
Click [save].
If you want us to automatically complete those details in the dispatch form, set the default sender address and the courier pickup address. You can do it while adding or editing a given address.
If you add only one address, we automatically set it as default. If you do not add any address to the Address Book, we will complete the sender's details in the dispatch form with your Allegro account details.
Shipping labels
In the
Label printing
option group, you will set the file type and format of labels generated for parcels dispatched within Ship with Allegro. You will also add a summary that helps you match a label with an order. You can download a sample label anytime to check the changes before saving.
How to select the shipping label format
In the
Delivery settings
, go to the Ship with Allegro Settings, and then select the
Label printing
tab.
In the
Labels
field, select the file format in which you want to download the labels:
ZPL — for thermal printers
PDF.
If you want to download the labels in PDF, select the format of the paper you will print on. Decide also whether you need the cut lines between labels.
Click [save].
Done! We will save the future labels in the format selected by you.

If you only change the paper format, you will print labels with the new setting for already ordered parcels, too. Other changes will apply only to new parcels.

How to generate a summary for an order
Select
Add order summary
.
Decide:
how to print the summary — for each label separately, or at the end after all labels
what data you need in the summary — for example, order ID, tracking number, purchase notes, or the buyer's login.
Click [save]. Done! We will generate the summary for you as an attachment to all your labels.
If you do not want to use the summary option, you can disable it and enable it again at any time.
