Currently, we use automatic translation to translate your product descriptions to:
Polish
Czech — if you dispatch parcels to Czechia
Slovak — if you dispatch parcels to Slovakia
Hungarian — if you dispatch parcels to Hungary
Ukrainian — only the title, regardless of the delivery options you offer.
In the
Translations
section, you can add your own translations from English to:
Polish
Czech
Slovak
Hungarian
Ukrainian — the title and the product description.
How to use the Translations section
You can access the
Translations
section from the
My Assortment
tab. There, you can:
add or edit your own translations
restore automatic translations
compare different translations
compare translations with source texts — for example, in English.
You can also manage translations through the listing form and
Allegro API
.
Translating offers in foreign marketplaces
Each offer you want to
share in foreign marketplaces
should have the proper language version. You can easily use the automatic translation option.
How it works
When you
share your offer in a foreign marketplace
, we check whether it is translated into the language of the selected marketplace. If not, we add the automatic translation. That way foreign customers will understand your offer description.
You can also edit the automatic translation or enter your own.

The buyer sent you a message in a language you do not know? You can translate it into the language you use on Allegro in the
Message Center
.
Make shopping easier for buyers from abroad and add your own or automatic translation of the
warranty
and the
complaints terms
.

Adding a new translation in the My Assortment tab
You can add translations in active, expired, and draft offers. To add a new translation:
Go to the
My Assortment
tab. In the case of an active offer — click [more]. Next, click [edit] in the panel we will display on the right, in the Translations section. We will redirect you to the Translations panel.
In this panel, you can also check what kind of translations and to which languages you have already provided for the selected offer.
If you want to add a translation to a draft offer, hover over the three dots and select
Translate offer
from the menu. We will redirect you to the translation list of a given offer.

Click [add] next to the language you would like to add your own translation in.
Enter the offer title and description in the selected language.
Click [save].

When you add your own offer translation, we will no longer automatically update its description and title after you change the source text.

You can also add product images to your translation. Those images can be different than in the original offer — for example, showing the product from a different perspective. You can add images in a different order than in the original offer. However, you can add an image only if it had been added to the original offer gallery.
Adding a new translation in the listing form
Click [add your own translation] in the
Product description
section. There, you can translate the title and description to Czech, Slovak, Hungarian, Polish, and Ukrainian.
Enter the title, description, and click [save translation].
How to translate an extensive offer description:
First, add images.
Then, determine the layout of the text and images.
Finally, add your own translation.
Editing translations
To edit a translation:
Click [edit] in the translations list of a given offer, next to the language version you want to correct.
Make changes — edit your own translation or restore an automatic one. You can do it with the [automatic translation] button.
When you finish editing, click [save].
Comparing the translation with the original text
To compare the translation:
Click [compare] on the translations list of a given offer, next to the translation you want to compare.
Select the language version you want to compare the translation with. If you want to compare the translation in Czech, Slovak, Hungarian, or Ukrainian, you can choose to compare the text with the Polish or English version. In the case of the Polish translation, you can compare it only with the English version.
If you have to make changes to the translation, you can do it right away, without going to the translation edition screen.
When you enter the changes to the translation, click [save].
Automatic translation of offers
If you do not add your own translation, we will automatically translate:
the offer title and description to
Polish
the offer title to
Ukrainian
the offer title and description to
Czech
— if you enable dispatch to Czechia in your offer
the offer title and description to
Slovak
— if you enable dispatch to Slovakia in your offer
the offer title and description to
Hungarian
— if you enable dispatch to Hungary in your offer.
We will not automatically translate the offers you list in the
categories excluded from translation
(the file is available only in Polish).
