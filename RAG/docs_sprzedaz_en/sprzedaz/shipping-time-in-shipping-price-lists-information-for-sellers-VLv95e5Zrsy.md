Shipping time is one of the factors we use when calculating the
estimated delivery time
displayed in your offers.
For most delivery options, we automatically complete shipping times in the price lists and update them regularly. The estimates we give are based on our analyses and carriers' declarations.
You can see them in your shipping price lists, next to each delivery option you select in:
the
Delivery Settings
tab
the listing form, if you add delivery options manually.

See the table
with current shipping times for particular delivery options.

For some delivery options, you can
edit the shipping time
manually yourself.
How to edit the shipping time
Go to the relevant shipping price list in the
Delivery Settings
tab to edit the shipping time. Just click the time frame next to the selected delivery option and provide your own.
Additional information
If you edit the shipping time to be
shorter than the one we set
, we will save the change in the price list, but we will use our data to calculate the delivery time displayed in your offers. We do that because we want the delivery times to be realistic and possible to fulfill.

You have enabled delivery by priority letter in your offer. The shipping time we display in the price list for this option is 2–3 days. If you change it to 1–2 days, we will save that. However, to calculate delivery times for offers with this price list, we will use the timeframe we have determined ― 2–3 days.

If you edit the shipping time to be
longer than the one we set
, we will save it in the price list and use it to calculate shipping time we display in your offers.

You have enabled delivery by priority letter in your offer. The shipping time we display in the price list for this option is 2–3 days. If you change it to 10–11 days, we will save it and use it to calculate delivery times for offers with this price list.

If you dispatch parcels from outside Poland, select the delivery options in which you can set and edit the shipping time yourself. Look at the time frames in the tables below, select the relevant delivery option, and provide the correct shipping time.

You can add a given delivery option only once within one shipping price list. For example, if you set the time for a courier delivery to up to 10 days, you cannot add a courier delivery with a different delivery time later. However, you can create two separate shipping price lists and set different shipping times for courier deliveries in each.
