On Allegro, there are specific regulations and restrictions that apply to listing offers and creating their descriptions. They are included in the
Allegro Terms & Conditions
. You can find the detailed explanations of individual issues below.
How to prepare a description according to our rules
What conditions the description must meet:
the description should be complete and comprehensive — it cannot be cut off halfway
the description cannot contain linguistic or spelling errors, typos, or unnecessary phrases that do not fit
the description should be provided in the language of the marketplace in which you list a product — do not mix languages within one offer
the description should only concern the item that you sell in the offer
the description should be consistent with the offer name and the provided parameters
the description should be consistent with the images in the offer
the description should not include information about
other
product variants — check
how and when we display variants in an offer
the description must not include advertising and marketing phrases, for example — free, cheap, promotion, hit, gift
in the product description,
keywords
that may affect search results are not allowed
the description cannot contain any contact information, such as a phone number, email address, payment information, or a bank account number
the description must not include information about holidays, sales break, warranty, expiration date, warning about a short expiration date, product personalization, or data available in the
About Seller
section
the description should concern only the product you sell. Do not include information about other products in the description — even if they are available in your other offers.
the description must not include information about the product's place of origin — for example, specific distributor or manufacturer.
What else you should pay attention to:
the description should be clearly structured — include headings and bullet points, divide it into sections or paragraphs. You can highlight important words or parts using bold font.
the description should be in line with the spelling and grammar rules in the given language. If you are using Polish, make sure to inflect words correctly. Follow the correct word order and grammatical case. Remember about correct spelling of proper nouns and measurement units.
the description should not include repetitive photos (the same shot)
the description should not include information or suggestions regarding the marketplace the product is intended for (for example, user manual only in the given language)
the description should not include imprecise information about product quantity, for example — by ordering one unit, you buy 10 cm of the product. Such information is defined by the
unit price
. We display it automatically in selected categories.
the description should not include information about how the product is stored before dispatch.

How to check if the offer description is compliant with the rules
In order to help you create a proper offer description, we have launched a special tool that takes care of the quality of your descriptions.
The tool is based on a list of defined phrases and operates in real time. If you enter a phrase that is against the rules while listing an offer ― we will underline it in yellow immediately.
See the examples
Example 1
In the offer description, you provide contact details or encourage customers to buy from you — it is against our rules. Therefore, the tool will underline that information.
When you hover over the underlined phrase, you will see additional information and a hint on what you should correct.
You cannot list the offer if you do not make the suggested changes and leave the description in its original form. When you click [list and accept the conditions], you will see a message. It will tell you what to change in the offer description to list the offer.
Example 2
You will not list an offer if you try to list a product whose sales on Allegro is forbidden. If you provide the name of such a product in the title field, you will see a message. It will tell you why you cannot sell this product.
If you click [list item] anyway, you will see another message. It will inform you that you cannot list an offer with this product.
