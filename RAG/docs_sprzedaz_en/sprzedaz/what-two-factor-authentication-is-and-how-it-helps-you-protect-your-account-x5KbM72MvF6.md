How two-factor authentication works
If you have this protection enabled, during sign-in, we will ask for:
your username and password
a one-time code that:
we send you in a text message
or
you generate in the mobile app.
That way, even if someone steals the password for your Allegro account, they will not be able to sign in — because only you have the one-time code.
To make two-factor authentication more convenient, you can add your device to trusted devices. Then, you will not need to enter the code every time you sign in.
Check how to use this option
.

You cannot enable two-factor authentication on your phone if you have enabled
signing in with a phone number
on your account.

How to enable two-factor authentication
You will enable two-factor authentication in the tab with the same name. The process will look different, depending on how you want to receive the one-time codes.
How to enable two-factor authentication with text message (SMS) codes
Open the
Two-Factor Authentication
tab and click [Let us begin].
Select text messages as the way to receive the codes and click [next].
Enter the phone number to which you want us to send codes. If that phone number is already assigned to your account — you can select it from the list or enter a new one.
Next, click [send code].
Enter the code from the text message you receive.
Click [enable]. Done!
How to enable two-factor authentication with a code generating app
Open the
Two-Factor Authentication
tab and click [Let us begin].
Select the code generating app and click [next].
Choose the type of device on which you want to generate codes and click [next].

If you are using a mobile device, we will automatically recognize it and take you straight to the next step.

You will see a short guide on how to configure the app on your chosen device. We will also display a QR code. If you cannot scan it, click
Show code
and use it in text form. Once you have completed all the steps, click [next].
Enter the code from the app and click [enable].
For security reasons, provide a phone number to which you want to receive a text message with the code when you cannot access the app. If that phone number is already assigned to your account — you can select it from the list or enter a new one.
Next, click [send code].
Enter the code from the text message you receive. Done!
How to disable two-factor authentication
Open the
Two-Factor Authentication
tab.
Click [disable] next to the
Two-factor authentication is enabled
message.
Confirm your choice. Done!
What a trusted device is
If you are the only user of the device with which you often sign in to Allegro, you can add it to trusted devices — a
list of devices you have chosen, where we do not ask for a one-time code during sign-in
.
This means we will only require a code when you use an unknown device or when someone tries to hack into your account. On a daily basis, you will sign in quickly and conveniently.

If you clear the cookies or change the settings in your browser, we will no longer recognize your device as trusted. In such a case, we will ask you for a one-time code during sign-in. We will also do this if you use a different web browser or private (incognito) mode.

How to add a trusted device
You can do it in the
Two-Factor Authentication
tab or while signing in on that device.
How to add a trusted device in the Two-Factor Authentication tab
Open the
Two-Factor Authentication
tab on the device you want to add to trusted devices.
Click [add to trusted] in the
Trusted devices
section.
How to add a trusted device during sign-in
Open the
sign-in page
on the device you want to add to trusted devices.
Enter your username and password. Click [sign in].
Enter the code from the text message or app.
Select the
Do not ask for a code on this device
option.
Click [confirm code].
How to change the phone number used for two-factor authentication
Open the
Two-Factor Authentication
tab.
In the
Text message
section, click [change settings].
Click [change phone number].
Provide the new phone number and click [send code].
Enter the code you received on the new number.
Click [change phone number]. Done!
What you can do if you have not received the SMS code
If you can sign in with a different method, such as the app code, do so and go to the
Two-Factor Authentication
tab to see if you have:
enabled two-factor authentication
provided the up-to-date contact number — it can differ from the one in the
account details
.
If you cannot sign in with a different method — contact us.
